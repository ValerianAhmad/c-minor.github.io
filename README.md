## 📝 Deskripsi

C Minor merupakan website landing page yang dikembangkan untuk memperkenalkan komunitas atau organisasi melalui tampilan yang modern, sederhana, dan informatif. Website ini menyajikan informasi mengenai profil komunitas, visi dan misi, kegiatan, serta kontak sehingga pengunjung dapat mengenal komunitas dengan lebih mudah. Website dirancang dengan pendekatan responsive web design agar nyaman diakses melalui desktop maupun perangkat mobile.

---

## 🎯 Tujuan

- Membangun website landing page yang informatif.
- Menampilkan identitas komunitas secara profesional.
- Memudahkan penyampaian informasi kepada pengunjung.
- Mengimplementasikan konsep responsive web design.

---

## ✨ Fitur

- Responsive Landing Page
- Hero Section
- About Section
- Visi & Misi
- Informasi Kegiatan
- Contact Section
- Smooth Scrolling Navigation
- Mobile Friendly
